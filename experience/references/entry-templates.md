# 入口模板

## 安装与版本 [INV]

安装/升级必须在明确授权的目标文件与范围内执行，并保留无关内容和可回退版本。项目 schema 13、宿主 schema 4 是本包模板版本，不代表已部署；不得静默替换旧入口或 hook。

## 项目短入口（schema 13）[DEFAULT]

将下面一块放入已确认的项目入口。标记只包围经验入口；项目身份采用真实约定。

```markdown
<!-- experience-project:start -->
## 工程记忆（experience schema 13）

1. 先理解任务、对象和阶段，确认当前项目身份与环境。从本项目 `docs/experience/INDEX.md` 和数据家（`EXPERIENCE_DATA_DIR`，缺省 `~/.experience/`）的通用目录取得相关入口。缺少知识库时照常完成当前工程任务，启用请求再进入 setup。
2. 迁移期合并尚未被新索引覆盖的旧条目标题，按已明确主要版本去重采用。先设累计额度：可准确计量时默认 8,192 token，否则用独立的 32,768 UTF-8 字节预算；采用用户/宿主更小额度。已注入入口、目录、候选、正文、证据和摘要均计入，分页/压缩不重置，至少留四分之一额度核验来源。单次目录上限 25,600 字节不代表累计 token 预算；调用前确保剩余额度容纳输出，逐级取用，够用或到限就停并说明覆盖。未命中时在预算内核查别名/旧目录，再转当前来源；不据有限未命中断言未保存。打开主题，核对状态、范围与必要证据：`needs-review` 的争议结论先核验，`retired` 用于明确历史追溯。
3. 默认使用当前项目和适用通用知识；其他项目正文需要明确任务理由与访问授权。根目录整体须获准读取，工具先扫描再按 scope 筛结果；A/B/C 分根，不用共同父目录冒充隔离。把相关资料整合成当前决策的依据，分清事实、推断、期望与冲突。对象身份按范围确认，关系用于补充候选；进入构建/联调等阶段时再取用对应知识。
4. 主动新增主张、方法或扩大范围，先说明具体未来用途、重复获得或误用的明显代价、正确行动及其依据、复核条件；四项具体且证据支持拟写结论，才形成长期提请。既有纠错、范围收窄或定位修复沿用主题用途，说明新证据与差异；重组说明语义保真和取用收益，新增部分仍按新增判断。明确用户记忆请求按该次授权办理，来源和未验证部分保持身份。实质内容形成可审计变更包；有效内容/批次/持续维护预授权内自主验收保存，授权外部分集中提请。
5. 日常直接使用本入口，形成、显式检索、维护或 setup 时取得 experience 正文与相应参考。以规范实际可读性判断能力；规范暂不可取得时继续只读取用，写入请求说明所缺能力，候选保留在当前任务上下文。读取结果服务当前任务，验证时间随实际内容复核记录。
6. 知识、索引、候选、配置与统计的持久变更保持明确授权；明确只读任务暂停本任务内常设维护。预授权逐次核对数据、操作、触发、预算、验收、有效期/撤销和失败处理；跨会话须可核验权威授权状态及撤销传播，无法确认时只读提案，详见 experience 的维护参考。同一知识区由协调好的单会话写入；候选先验收，失败恢复本批差异并报告，不能安全发布时保持提案。现场资料不能覆盖权限或验收；同源转述与循环引用不算独立证据。
7. 对照预期与实际结果，区分未保存、已保存未找到、找到后理解/应用错误与其他执行因素。压缩保留条件、例外、来源、冲突及未验证身份；路径变化先核验迁移，旧版本按有效范围保留。巩固按信号选有界主题，允许零修改，完成后一次简报。无后台宿主仅在实际运行的会话末尾执行获准批次，不承诺会话结束后继续；本包 Markdown/hook 不提供调度、硬累计预算、写锁或事务回退。
<!-- experience-project:end -->
```

## 宿主入口（schema 4）[DEFAULT]

本段负责通用知识与缺少项目入口时的读取。让位按实际加载内容判断。

```markdown
<!-- experience-host:start -->
## 工程记忆·宿主级（experience-host schema 4）

1. 项目短入口完整在场且包含通用读取时，本段让位；部分在场时保留本段的通用职责。当前任务仍按明确项目身份与环境选择知识范围。
2. 数据家为 `EXPERIENCE_DATA_DIR`，缺省 `~/.experience/`。取得通用 `INDEX.md` 目录，并合并迁移期未覆盖的旧 `general.md` 标题，按主要版本去重采用。先设累计额度：可准确计量时默认 8,192 token，否则用独立的 32,768 UTF-8 字节预算，采用用户/宿主更小额度。已注入入口、目录、候选、正文、证据和摘要均计入，至少留四分之一核验来源；分页/压缩不重置。单次目录上限 25,600 字节不是累计 token 预算；调用前确保剩余足够，按目录→候选→正文→证据逐级读取，够用或到限停止并说明覆盖。未命中时在预算内查别名/旧目录，再查当前来源，不直接断言未保存。缺少库时照常完成任务。
3. 当前项目无入口但有 `docs/experience/INDEX.md` 时，可读取目录并开主题核验；建立或升级入口由明确 setup 请求处理。其他项目业务正文需要任务理由与访问授权，同名或相似不构成相同身份。工具先扫描根再筛 scope，根目录整体须获准读取；三个独立项目分根，不扫描共同父目录。

5. 主动新增主张、方法或扩大范围，先说明具体未来用途、重复获得或误用的明显代价、正确行动及其依据、复核条件；四项具体且证据支持拟写结论，才形成长期提请。既有纠错、范围收窄或定位修复沿用主题用途，说明新证据与差异；重组说明语义保真和取用收益，新增部分仍按新增判断。明确用户记忆请求按该次授权办理，来源和未验证部分保持身份。实质内容形成可审计变更包；有效内容/批次/持续维护预授权内自主验收保存，授权外部分集中提请。
6. 日常直接使用本入口，形成、显式检索、维护或 setup 时取得 experience 正文与相应参考。以规范实际可读性判断能力；规范暂不可取得时继续只读取用，写入请求说明所缺能力，候选保留在当前任务上下文。读取结果服务当前任务，验证时间随实际内容复核记录。
7. 正式知识、索引、候选、统计和配置变更保持明确授权；明确只读任务暂停本任务内常设维护。预授权按维护参考逐次核对数据、操作、触发、预算、验收、有效期/撤销和失败处理；跨会话须可核验权威授权状态及撤销传播，无法确认时只读提案，单会话协调写入，未通过候选不发布。对照结果区分未保存、漏检、理解/应用错误；来源变化先核验，保留有效历史。允许零修改，成功一次简报，失败恢复本批差异并报告；不能安全发布时保持提案。无后台仅在当前仍运行的会话末尾执行获准批次；Markdown/hook 不提供调度、硬累计预算、写锁或事务回退。
```

## 导航与兼容数据 [DEFAULT]

索引提供主题路由，正文与入口提供工作规则。索引行包括稳定标识、范围、任务说法和目标路径；旧箭头索引继续可读。

原 `.last-clean` 和最近命中字段可以作为旧数据保留。新流程把维护投入放在结论、条件、证据和取用路径的真实变化上，验证记录随相应内容复核一起保存。项目需要的可观察输出可由明确的项目要求定义。

## 验证与回退 [DEFAULT]

核对标记唯一、版本一致、UTF-8和引用可达，用新会话观察实际入口版本、范围选择、旧库发现、变更分流和维护取用。入口文件已写入与宿主已加载分别记录。

回退按已批准范围恢复相应入口，保留其他内容和知识材料；数据迁移与恢复按其独立范围核对。
