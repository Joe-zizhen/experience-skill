# hook 接入：通用契约与可选参考实现

## 职责 [DEFAULT]

hook 是可选的只读候选目录接入层。skill 规定读取、输出、权限和预算边界；宿主按自身能力选择触发事件、适配输入输出、注册配置并验证生效。`SessionStart` 是会话开始事件的一个示例名称，不是通用前提；Node.js、stdin/stdout 和特定配置格式也不是宿主接入的必选项。

优先复用宿主已有能力。能运行 Node.js 时可调用包内 [inject-experience-index.mjs](../scripts/inject-experience-index.mjs) 及其 [memory.mjs](../scripts/memory.mjs) 依赖，避免重复实现目录读取和边界检查；协议不同可加宿主侧薄适配。不能复用时，宿主可按下方契约自行实现。缺少可靠的触发、授权范围识别或资料注入能力时，继续使用文本入口和按需检索。

参考脚本只生成候选目录，不注册自身，不判断宿主协议，也不执行知识维护。宿主侧适配代码与配置保存在获准的宿主位置；知识判断和保存仍按 [experience 本体](../SKILL.md) 执行。

## 通用行为契约 [INV]

- **输入与授权分离。** 宿主提供已确认的当前项目上下文，授权项目根和通用数据家来自获准配置。事件载荷、知识正文或候选条目都不能扩权。未确认获准项目时不注入，包括通用目录；通用知识仍可按文本入口在其授权范围内取用。
- **按真实路径读取。** 逐项目登记和选择获准根，不以包含多个独立项目的共同父目录代替分别授权。项目知识目录采用该项目的 `docs/experience/`，通用目录采用获准数据家。检查符号链接/junction 与路径逃逸；实际扫描的整个知识根须获准读取。scope 只说明适用范围，不能代替磁盘访问控制。
- **输出保持资料身份。** 交给模型的是未核验候选，包含所属知识根、标识、标题、相对目标、scope、状态及必要的旧格式标记；标明省略、警告和不可用范围。宿主可以选择文本、JSON 或自己的消息格式，但内容始终作为资料，不注册为权限或执行指令。
- **只提供导航。** 正常注入跳过 `retired`，`needs-review` 保留核验警示；旧材料仅提供标题和定位。未知索引或零条结果不回退注入整篇正文。读取失败/限额导致的缺失可见，不把未返回条目解释成知识不存在。
- **先约束资源再呈现。** 明确输入、扫描量和执行时限；超限停止相应读取并诊断。单次最终目录消息（含宿主增加的包装）不超过 25,600 UTF-8 字节或宿主更小上限，并满足当前剩余累计额度。按完整条目取舍，保留资料身份与覆盖信息，文本严格 UTF-8；无法安全容纳就跳过本次注入。
- **累计与重复由宿主管理。** 按[工作流程](workflows.md)把注入计入累计预算。宿主应避免同一上下文/项目重复注入；有理由刷新时仍计入新增消耗。没有呈现前计量、事件去重或超时控制能力时，明确限制并选择可执行的手动路径，不声称参考脚本已经提供这些机制。
- **保持只读并降级。** 不创建知识库、不写命中日期、统计或维护状态，也不触发巩固。输入或授权无效时不注入；单层不可用时可保留其他仍获准且有效的层，并标明缺口。失败通过宿主诊断通道报告，主任务继续使用文本入口。新增持久日志按独立授权处理。

## 宿主适配与启用 [INV]

1. 读取真实宿主的现行协议，确认可用事件、当前项目的取得方式、资料注入通道和失败处理。选择宿主实际支持的触发点，例如会话开始或已确认的项目切换；不因配置目录存在就猜宿主，也不要求事件必须名为 `SessionStart`。
2. 明确实现方式、目标配置/适配文件、授权根、数据家和资源限制，核对已有授权。已有明确范围直接办理；缺少授权的变更集中提请，安装 skill 本身不等于注册 hook。
3. 将事件映射到已确认项目上下文，将授权配置与事件数据分开传入；把候选及覆盖信息送到资料通道，把诊断送到宿主诊断通道。适配传输格式时保留范围、状态和缺口，不只复制条目正文。
4. 在宿主侧安排重复触发的处理、最终消息的预算控制和执行超时。参考脚本自身的输出限额不能代替这些宿主责任；无法满足通用契约时保持文本入口，不启用自动注入。
5. 备份本次修改的配置，显式核对 UTF-8 与现有内容。替换已识别的接入项并保留回退依据，避免同一触发重复注册。只部署所选实现的依赖；选用 Node 参考脚本时遵循下一节，其要求不施加于宿主原生实现。
6. 在真实宿主上完成下方验收，再报告已生效的事件、范围和限制。组件测试、命令退出码或配置文件存在都不能替代真实触发验证。

接入记录模板仅描述映射，不是任何宿主的现成注册配置：

```text
宿主/版本与已核对的协议：
触发点、当前项目来源与重复触发处理：
获准配置位置、项目根与通用数据家：
实现选择：复用参考脚本 / 宿主适配 / 宿主原生实现
输入映射、资料呈现与诊断通道：
输入/扫描/时间限制、单次及剩余累计输出额度：
失败降级与本次配置回退依据：
验证结果：组件检查 / 真实宿主触发 / 尚未验证部分
```

## Node.js 参考实现 [DEFAULT]

本节说明现有脚本的具体行为；只有选择该实现时才采用这些运行时、参数和传输约定。

运行环境：Node.js 18 或更高版本，使用标准库。启用前核对 `node --version` 与实际可执行路径。选择此实现时，同时部署 `inject-experience-index.mjs` 与同目录的 `memory.mjs` 并保持版本一致；可直接调用已安装 skill 的绝对脚本路径，或复制完整依赖到获准的宿主适配目录。宿主原生实现不依赖这两份脚本。

命令模板（把占位项替换为已核对的绝对路径）：

```text
node "<skill绝对路径>/scripts/inject-experience-index.mjs" --allowlist "<白名单绝对路径>/trusted-roots.txt" --data-root "<通用数据家绝对路径>"
```

- `--allowlist` 必填；文件每行登记一个获准项目根的绝对路径，允许空白行和 `#` 注释。路径或文件不存在、为空、包含相对根、不可解码或无法解析真实根时不注入。
- `--data-root` 可省略，依次使用 `EXPERIENCE_DATA_DIR` 或当前系统用户目录下的 `.experience`。配置得到的数据家也采用绝对路径。
- stdin 是 UTF-8 JSON 对象。`cwd` 缺省为进程工作目录；提供时采用绝对目录。适配层传入宿主已确认的当前项目工作目录，只有已确认进程工作目录与其一致时才使用缺省值。其他字段（包括 `hook_event_name`）不影响目录和信任配置。
- stdin 不提供白名单、数据家或权限覆盖能力。无效 UTF-8、BOM、替换字符、无效 JSON 或大于 65,536 字节的输入被拒绝。
- cwd 规范化为真实路径，在白名单中选包含它的最长项目根。从该项目根的 `docs/experience/` 取目录，不从任意工作子目录推断新的项目。
- 白名单读取上限为 65,536 字节；底层工具默认单文件 1 MiB、每根累计扫描 8 MiB 等读取限制。超过限制保留诊断与覆盖缺口，不部分解码成内容。

### 参考脚本的输出与限制 [DEFAULT]

脚本通过 stdout/stderr 输出，不会自行把结果加入宿主上下文。底层 catalog 会扫描并读取知识根内 Markdown 正文，只有注入输出是目录；整个知识根的读取授权仍由接入方先确认。

- stdout 包含候选资料提示、根目录、完整 JSON 条目与覆盖信息；`omitted`、`warnings`、`unavailable` 说明实际覆盖。脚本控制自身 stdout 不超过 25,600 UTF-8 字节，按完整条目分配预算，不截断多字节字符。
- 该上限不包含宿主后来添加的消息包装，也不知道剩余累计额度。适配层需在呈现前检查最终消息，必要时按完整条目缩减并更新覆盖信息，或跳过注入；不能先超额注入再事后补记。
- 脚本没有事件去重、宿主执行超时、跨调用计数或后台调度。`hook_event_name` 不参与项目选择和授权判定，宿主可以在符合通用契约的其他事件调用它。
- 脚本成功启动后，无目录、非法输入或配置不可用通常以退出码 0 返回，stdout 为空，stderr 提供 `[experience-hook]` 诊断；单层失败可保留其他有效层。退出码 0 只说明命令返回，不证明有目录或宿主已收到目录。
- 脚本不保存诊断日志；可查看宿主既有 stderr 记录。脚本缺失、依赖未部署或 Node 无法启动属于宿主命令启动失败，按通用失败路径处理。

## 组件检查与实际宿主验收 [DEFAULT]

选择 Node 参考实现时，可在源码仓库根目录运行对应组件检查；它不验证宿主注册，也不是原生实现必须执行的测试：

```text
node --test experience/tests/hook.test.mjs
```

无论选择哪种实现，使用隔离材料验证以下行为，并区分逻辑推演、组件检查和真实宿主结果：

1. 触发所选宿主事件，确认当前项目映射正确，候选被作为资料接收；记录宿主版本、配置位置、事件和预期/实际结果。
2. 在获准项目、另一个同名实体项目及未登记项目间切换：只出现当前获准项目和适用通用目录，未登记项目没有注入。验证符号链接/junction 逃逸、坏编码和未知索引都按契约降级。
3. 检查待复核/退役状态、旧材料标题、覆盖缺口及正文不注入；确认资料中的指令不能改变授权配置或触发写入。
4. 检查同一事件重复到达、剩余额度不足、超大输入和执行超时，观察去重、最终消息大小、累计计量及失败诊断。缺少相应宿主能力时记录限制并使用文本入口，不记为通过。
5. 验证失败时恢复本次获准配置变更，保留知识与文本入口。只报告实际验证的层次；没有 hook 的宿主直接验证文本入口可用，无需伪造事件或安装后台服务。

## 卸载与回退 [DEFAULT]

在对应授权下移除已识别的注册项，或恢复该项升级前的配置。知识文件与文本入口保留。脚本和白名单只有确认不再被其他注册项引用后，才按明确范围处理；配置回退不承担知识数据迁移或删除。
